# ViajesApp - Agencia de Viajes

Aplicacion web para busqueda interactiva y reserva en linea de vuelos y paquetes turisticos.

## Funcionalidades

- Busqueda de vuelos por origen, destino y fechas
- Visualizacion de destinos populares
- Simulacion de resultados de busqueda
- Reserva de vuelos

## Instalacion

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. No se requieren dependencias adicionales
